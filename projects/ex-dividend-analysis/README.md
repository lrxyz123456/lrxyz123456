# Ex-Dividend Analysis

A Python project for exploring stock-price behavior around ex-dividend dates using market data from yFinance.

## What it does

- Downloads dividend history for a selected ticker
- Identifies recent ex-dividend dates
- Pulls stock prices around the event window
- Visualizes price movement and dividend history
- Exports dividend data to CSV
- Includes a multi-event analysis script for comparing price changes around ex-dividend dates

## Tools

Python, yFinance, Pandas, NumPy, Matplotlib

## Run

```bash
python ex_dividend_analysis.py
```

This project is for educational and analytical purposes only.
